2. การบีบอัดและข้อมูลในเครื่อง

Compresser จะบีบอัดไฟล์รูปภาพ วิดีโอ เสียง และ PDF บนอุปกรณ์ของคุณ การบีบอัดจะไม่ทำการอัปโหลดไฟล์ของคุณแต่อย่างใด แอปจะจัดเก็บการตั้งค่า สถิติ และประวัติการบีบอัดไว้ในเครื่อง ซึ่งรวมถึงชื่อ ประเภท ขนาด และวันที่ของไฟล์ คุณสมบัติและบริการเสริมอื่นๆ ที่อธิบายไว้ด้านล่างอาจมีการถ่ายโอนข้อมูล

3. การแจ้งเตือนทางเลือก

หากคุณเปิดใช้งานประกาศและอนุญาตสิทธิ์ของระบบ แอปจะลงทะเบียนโทเค็นพุชของ Expo และรหัสอุปกรณ์แบบสุ่มถาวรกับแบ็กเอนด์ Cloudflare ของเรา พร้อมทั้งแพลตฟอร์ม ภาษา เวอร์ชันแอป สถานะพรีเมียม และแชนเนลการเผยแพร่ นอกจากนี้ยังอาจมีการจัดเก็บประทับเวลาของการลงทะเบียนและกิจกรรมด้วย ทั้งนี้ Expo และบริการแจ้งเตือนพุชของ Apple (APNs) หรือ Firebase Cloud Messaging (FCM) จะช่วยในการส่งการแจ้งเตือน แอปจะทำการรีเฟรชการลงทะเบียนในขณะที่เปิดใช้งานอยู่

คุณสามารถปิดประกาศในแอปและเปลี่ยนสิทธิ์การแจ้งเตือนได้ในการตั้งค่าอุปกรณ์ หากคุณออฟไลน์อยู่ คำขอปิดต้องรอจนกว่าจะสามารถส่งได้สำเร็จ จนกว่าจะถึงตอนนั้นการลงทะเบียนอาจยังคงใช้งานได้ หลังจากคำขอปิดสำเร็จ เราจะลบโทเค็นพุชและรายละเอียดการลงทะเบียน เราเก็บบันทึกขั้นต่ำที่เชื่อมโยงกับ ID อุปกรณ์แบบสุ่มเพื่อป้องกันไม่ให้คำขอเก่าลงทะเบียนอุปกรณ์อีกครั้ง ติดต่อเราเพื่อขอลบ การลงทะเบียนที่ใช้งานอยู่จะถูกเก็บไว้จนกว่าคำขอปิดจะสำเร็จ

4. การวินิจฉัย การโฆษณา และการซื้อ

Sentry จะได้รับเหตุการณ์การวินิจฉัย เช่น ข้อขัดข้อง สแต็กเทรซ (stack traces) เวอร์ชันแอป และข้อมูลอุปกรณ์หรือระบบปฏิบัติการ เพื่อช่วยเราแก้ไขข้อผิดพลาด แอปจะกรองเหตุการณ์การวินิจฉัยและปกปิดข้อความที่เป็นข้อความอิสระและข้อความข้อยกเว้น ตัวกรองนี้ไม่ได้ครอบคลุมการส่งข้อมูลทุกรูปแบบที่เป็นไปได้โดย SDK ของระบบ โปรดดูนโยบายความเป็นส่วนตัวของ Sentry สำหรับแนวปฏิบัติของพวกเขา

Unity Ads เป็นผู้ให้บริการโฆษณา SDK ของบริการนี้อาจประมวลผลตัวระบุโฆษณา ข้อมูลอุปกรณ์ และข้อมูลการโต้ตอบกับโฆษณาเพื่อส่งมอบและวัดผลโฆษณา ทั้งนี้ขึ้นอยู่กับการตั้งค่าอุปกรณ์และตัวเลือกความยินยอมที่เกี่ยวข้อง โปรดดูนโยบายความเป็นส่วนตัวของ Unity Apple หรือ Google จะประมวลผลการซื้อในแอปและข้อมูลบัญชี/การชำระเงินภายใต้นโยบายของตนเอง โดยแอปจะใช้ข้อมูลการซื้อเพื่อมอบหรือคืนสิทธิ์การใช้งาน

5. วัตถุประสงค์ ฐานทางกฎหมาย และผู้รับข้อมูล

สำหรับการประกาศ เราอาศัยความยินยอมของคุณ (มาตรา 6(1)(a)) คุณสามารถถอนออกได้โดยปิดเครื่องโดยไม่ส่งผลกระทบต่อการประมวลผลก่อนหน้านี้ เราใช้ข้อมูลการวินิจฉัยบนพื้นฐานของประโยชน์โดยชอบด้วยกฎหมายของเราในด้านความเสถียรของแอปและการแก้ไขข้อผิดพลาด (มาตรา 6(1)(f)) คุณสามารถคัดค้านได้ เราประมวลผลข้อมูลการซื้อและการให้สิทธิ์เพื่อจัดหาหรือเรียกคืนการซื้อ (มาตรา 6(1)(b)) สำหรับการโฆษณา ความยินยอมเป็นพื้นฐานที่จำเป็น (มาตรา 6(1)(a)) คุณสามารถเปลี่ยนตัวเลือกที่เกี่ยวข้องได้ในการตั้งค่าแอพหรืออุปกรณ์ ผู้ให้บริการ ได้แก่ Google, Apple, Cloudflare, Expo, Sentry และ Unity สำหรับบริการที่อธิบายไว้ข้างต้น การโอนระหว่างประเทศอาจเกิดขึ้นภายใต้มาตรการป้องกันที่เกี่ยวข้อง

6. การเก็บรักษาข้อมูลและทางเลือกของคุณ

ข้อมูลแอปในเครื่องจะยังคงอยู่จนกว่าคุณจะลบหรือล้างข้อมูลของแอป ทั้งนี้ขึ้นอยู่กับพฤติกรรมของระบบปฏิบัติการ การลงทะเบียนการแจ้งเตือนที่ใช้งานอยู่จะยังคงอยู่จนกว่าคำขอปิดจะสำเร็จ บันทึกขั้นต่ำที่ป้องกันการลงทะเบียนซ้ำโดยไม่ได้ตั้งใจยังคงอยู่เพื่อจุดประสงค์นั้น บันทึกการออกอากาศจะถูกเก็บไว้ในตอนแรกเป็นเวลา 90 วัน เมื่อตรวจสอบใบเสร็จรับเงินแล้ว ระยะเวลาเก็บรักษาจะรีเซ็ตเป็น 30 วันหลังจากการตรวจสอบครั้งล่าสุด Sentry, Unity, Apple และ Google ใช้แนวทางปฏิบัติในการเก็บรักษาของตนเอง ดูนโยบายหรือติดต่อเราหากมีคำถามเกี่ยวกับข้อมูลที่เราควบคุม

ขึ้นอยู่กับกฎหมายที่申请ใช้ คุณอาจขอเข้าถึง แก้ไข ลบ จำกัดการใช้งาน โอนย้าย หรือคัดค้านการประมวลผล และคุณอาจร้องเรียนต่อหน่วยงานกำกับดูแล สิทธิ์เหล่านี้อาจอยู่ภายใต้เงื่อนไขและข้อยกเว้น ติดต่อ mail@macsiem.dev

7. ความปลอดภัย เด็ก และการเปลี่ยนแปลง

เราใช้มาตรการรักษาความปลอดภัยที่เหมาะสมสำหรับบริการนั้นๆ แต่ไม่มีระบบใดที่ปลอดภัยอย่างสมบูรณ์ แอปนี้ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี โปรดติดต่อเราหากคุณเชื่อว่าเด็กได้ให้ข้อมูลส่วนบุคคล เราอาจอัปเดตโยบายนี้และเปลี่ยนแปลงวันที่ด้านบนเมื่อมีการเปลี่ยนแปลงแนวปฏิบัติ
