# LAME 3.100 source materials

[Download the source archive](lame-3.100.zip) and its [SHA-256 checksum](lame-3.100.zip.sha256). The archive contains the source, copyright and license texts, Android integration and build instructions used for Compresser's LAME library.

Verify the download with `shasum -a 256 -c lame-3.100.zip.sha256` in the download directory. Extract the archive and run `shasum -a 256 -c SHA256SUMS` inside it to verify its contents. See `scripts/notices/LAME-ANDROID.md` in the archive for rebuild and replacement instructions.
