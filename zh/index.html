隐私政策 — Compresser

最后更新时间：2026年11月15日

1. 数据控制者与联系方式

对于 iOS 版本，数据控制者为 Maciej Siemiński。对于 Google Play 版本，数据控制者为 LICENCEPRO POLSKA Sp. z o.o.，地址：ul. Huculska 6, 00-730 Warszawa, Poland。两者的联系邮箱均为：mail@macsiem.dev。

2. 压缩与本地数据

Compresser 在您的设备上压缩图像、视频、音频和 PDF 文件。压缩过程本身不会上传您的文件。应用程序会在本地存储设置、统计数据和压缩历史记录，包括文件名、类型、大小和日期。下面描述的其他可选功能和服务可能会传输数据。

3. 可选备份与导出

如果您的版本中提供帐户备份，并且您明确启动备份或恢复，则应用程序将使用选定的帐户：Google Drive 应用程序数据或 iOS 上的私有 Apple CloudKit 数据库。备份可以包含设置、统计数据、历史记录和可用的原始文件。它是加密的，但加密密钥与备份存储在同一帐户中；这不是针对帐户提供商的端到端加密。要删除云备份，请使用提供商的帐户存储控制； Google 云端硬盘应用程序数据不是“我的云端硬盘”中的普通文件。 Apple CloudKit 数据可以在 iCloud 存储设置中进行管理。本地出口到您选择的目的地；自己保护并删除该副本。

Compressor 仅使用从 Google Workspace API 获取的数据来根据您的请求备份或恢复数据。我们不会将这些数据用于广告、销售或训练人工智能模型。 我们对从 Google Workspace API 收到的信息的使用和传输符合 Google 的用户数据政策，包括其限制使用要求。

4. 可选通知

如果您启用公告并授予系统权限，应用程序会将 Expo 推送令牌和持久的随机设备 ID 以及平台、语言、应用版本、高级版状态和发布渠道注册到我们的 Cloudflare 后端。还可能会存储注册和活动时间戳。Expo 和苹果推送通知服务 (APNs) 或 Firebase Cloud Messaging (FCM) 有助于发送通知。应用程序在启用时会刷新注册。

您可以在应用程序中关闭通知，并在设备设置中更改通知权限。如果您处于离线状态，则关闭请求必须等待才能发送成功；在此之前，注册可能会保持有效状态。成功关闭请求后，我们会删除推送令牌和注册详细信息。我们保留与随机设备 ID 关联的最小记录，以防止旧请求再次注册设备。联系我们请求删除。活动注册将一直保留，直到关闭请求成功为止。

5. 诊断、广告与购买

Sentry 接收诊断事件（例如崩溃、堆栈跟踪、应用版本以及设备或操作系统信息），以帮助我们修复错误。应用程序会过滤诊断事件并编辑自由文本和异常消息；此过滤并不能描述原生 SDK 的每一次可能传输。有关其做法，请参阅 Sentry 的隐私政策。

Unity Ads 提供广告服务。其 SDK 可能会处理广告标识符、设备信息和广告互动数据以投放和衡量广告，具体取决于设备设置和适用的同意选择。请参阅 Unity 的隐私政策。Apple 或 Google 根据其自身的政策处理应用内购买以及账号/支付信息；应用程序使用购买信息来提供或恢复权益。

6. 目的、法律依据与接收方

对于请求的备份和恢复，我们会处理数据以执行您请求的服务（GDPR 第 6(1)(b) 条）。对于公告，我们需要您的同意（第 6(1)(a) 条）；您可以通过关闭它们来撤回它，而不会影响之前的处理。我们根据对应用程序稳定性和修复错误的合法利益使用诊断数据（第 6(1)(f) 条）；你可能会反对。我们处理购买和权利信息以提供或恢复购买（第 6(1)(b) 条）。对于广告，必要时同意是基础（第 6(1)(a) 条）；您可以在应用程序或设备设置中更改适用的选项。上述服务的提供商包括 Google、Apple、Cloudflare、Expo、Sentry 和 Unity。国际转移可能会在适用的保障措施下进行。

7. 数据保留与您的选择

本地应用程序数据将保留，直到您删除它或清除应用程序的数据，具体取决于操作系统行为。云备份和导出可以在卸载后保留，并且必须如上所述单独管理。活动通知注册将一直保留，直到关闭请求成功为止；为此目的保留了防止意外重新注册的最低记录。广播日志最初保留 90 天；当检查交货收据时，保留期限将重置为最近一次检查后的 30 天。 Sentry、Unity、Apple 和 Google 采用自己的保留做法；请参阅他们的政策或联系我们询问有关我们控制的数据的问题。

根据适用法律，您可能会请求访问、更正、删除、限制、可移植性或反对处理，并且您有权向监管机构投诉。这些权利可能会受到条件和例外情况的限制。请联系 mail@macsiem.dev。仅卸载应用并不会删除云端副本或第三方记录。

8. 安全性、儿童与变更

我们采用适合相关服务的保障措施，但没有任何系统是完全安全的。本应用并非面向 13 岁以下的儿童；如果您认为儿童提供了个人数据，请联系我们。当做法发生变化时，我们可能会更新本政策并更改上述日期。
