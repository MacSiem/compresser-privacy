Kebijakan Privasi — Compresser

Terakhir diperbarui: 15 November 2026

1. Pengendali dan kontak

Untuk versi iOS, pengendali data adalah Maciej Siemiński. Untuk versi Google Play, pengendali data adalah LICENCEPRO POLSKA Sp. z o.o., ul. Huculska 6, 00-730 Warszawa, Polandia. Kontak untuk keduanya: mail@macsiem.dev.

2. Kompresi dan data lokal

Compresser memikompresi gambar, video, audio, dan file PDF di perangkat Anda. Proses kompresi sendiri tidak mengunggah file Anda. Aplikasi ini menyimpan pengaturan, statistik, dan riwayat kompresi secara lokal, termasuk nama file, jenis, ukuran, dan tanggal. Fitur dan layanan opsional lain yang dijelaskan di bawah ini dapat mentransfer data.

3. Cadangan dan ekspor opsional

Jika pencadangan akun tersedia dalam versi Anda dan Anda secara eksplisit memulai pencadangan atau pemulihan, aplikasi akan menggunakan akun yang dipilih: data aplikasi Google Drive atau database pribadi Apple CloudKit di iOS. Cadangan dapat berisi pengaturan, statistik, riwayat, dan file asli yang tersedia. Itu dienkripsi, tetapi kunci enkripsi disimpan di akun yang sama dengan cadangan; ini bukan enkripsi ujung ke ujung terhadap penyedia akun. Untuk menghapus cadangan cloud, gunakan kontrol penyimpanan akun penyedia; Data aplikasi Google Drive bukanlah file biasa di Drive Saya. Data Apple CloudKit dapat dikelola di pengaturan penyimpanan iCloud. Ekspor lokal menuju ke tujuan yang Anda pilih; lindungi dan hapus sendiri salinan itu.

Kompresor menggunakan data yang diperoleh dari Google Workspace API hanya untuk mencadangkan atau memulihkan data sesuai permintaan Anda. Kami tidak menggunakan data ini untuk periklanan, penjualan, atau pelatihan model AI. Penggunaan dan transfer informasi yang kami terima dari Google Workspace API mematuhi kebijakan data pengguna Google, termasuk persyaratan Penggunaan Terbatasnya.

4. Pemberitahuan opsional

Jika Anda mengaktifkan pengumuman dan memberikan izin sistem, aplikasi akan mendaftarkan token dorong (push token) Expo dan ID perangkat acak persisten ke backend Cloudflare kami, beserta platform, bahasa, versi aplikasi, status langganan premium, dan saluran rilis. Pendaftaran dan tanggal waktu aktivitas juga dapat disimpan. Layanan Notifikasi Dorong Expo dan Apple (APNs) atau Firebase Cloud Messaging (FCM) membantu mengirimkan pemberitahuan. Aplikasi memperbarui pendaftaran saat diaktifkan.

Anda dapat mematikan pengumuman di aplikasi dan mengubah izin notifikasi di pengaturan perangkat. Jika Anda offline, permintaan off harus menunggu hingga berhasil dikirim; sampai saat itu pendaftaran mungkin tetap aktif. Setelah permintaan off berhasil, kami menghapus token push dan detail pendaftaran. Kami menyimpan catatan minimal yang ditautkan ke ID perangkat acak untuk mencegah permintaan lama mendaftarkan perangkat lagi. Hubungi kami untuk meminta penghapusan. Registrasi aktif disimpan sampai permintaan off berhasil.

5. Diagnostik, periklanan, dan pembelian

Sentry menerima peristiwa diagnostik seperti crash, jejak tumpukan (stack trace), versi aplikasi, serta informasi perangkat atau sistem operasi untuk membantu kami memperbaiki kesalahan. Aplikasi memofilter peristiwa diagnostik dan menyunting teks bebas serta pesan pengecualian; filter ini tidak menggambarkan setiap kemungkinan transmisi oleh SDK asli. Lihat kebijakan privasi Sentry untuk praktiknya.

Unity Ads menyediakan periklanan. SDK-nya dapat memproses pengenal iklan, informasi perangkat, dan data interaksi iklan untuk menayangkan serta mengukur iklan, tunduk pada pengaturan perangkat dan pilihan persetujuan yang berlaku. Lihat kebijakan privasi Unity. Apple atau Google memproses pembelian dalam aplikasi dan informasi akun/pembayaran di bawah kebijakan mereka sendiri; aplikasi menggunakan informasi pembelian untuk menyediakan atau memulihkan hak akses (entitlements).

6. Tujuan, dasar hukum, dan penerima

Untuk pencadangan dan pemulihan yang diminta, kami memproses data untuk menjalankan layanan yang Anda minta (Pasal GDPR 6(1)(b)). Untuk pengumuman, kami mengandalkan persetujuan Anda (Pasal 6(1)(a)); Anda dapat menariknya dengan mematikannya, tanpa mempengaruhi pemrosesan sebelumnya. Kami menggunakan data diagnostik berdasarkan kepentingan sah kami dalam stabilitas aplikasi dan memperbaiki kesalahan (Pasal 6(1)(f)); Anda mungkin keberatan. Kami memproses informasi pembelian dan hak untuk menyediakan atau memulihkan pembelian (Pasal 6(1)(b)). Untuk periklanan, persetujuan adalah dasar jika diperlukan (Pasal 6(1)(a)); Anda dapat mengubah pilihan yang berlaku di pengaturan aplikasi atau perangkat. Penyedianya antara lain Google, Apple, Cloudflare, Expo, Sentry, dan Unity untuk layanan yang dijelaskan di atas. Transfer internasional dapat dilakukan berdasarkan pengamanan yang berlaku.

7. Penyimpanan dan pilihan Anda

Data aplikasi lokal tetap ada hingga Anda menghapusnya atau menghapus data aplikasi, tergantung pada perilaku sistem operasi. Pencadangan dan ekspor cloud dapat tetap ada setelah penghapusan instalasi dan harus dikelola secara terpisah seperti dijelaskan di atas. Registrasi notifikasi aktif tetap ada hingga permintaan off berhasil; catatan minimal yang mencegah pendaftaran ulang yang tidak diinginkan tetap ada untuk tujuan itu. Log siaran awalnya disimpan selama 90 hari; ketika resi pengiriman diperiksa, periode penyimpanan diatur ulang menjadi 30 hari setelah pemeriksaan terakhir. Sentry, Unity, Apple, dan Google menerapkan praktik retensi mereka sendiri; lihat kebijakan mereka atau hubungi kami untuk pertanyaan tentang data yang kami kendalikan.

Bergantung pada hukum yang berlaku, Anda dapat meminta akses, koreksi, penghapusan, pembatasan, portabilitas, atau keberatan atas pemrosesan, dan Anda dapat mengeluh kepada otoritas pengawas. Hak-hak ini dapat tunduk pada ketentuan dan pengecualian. Hubungi mail@macsiem.dev. Menghapus instalan aplikasi saja tidak menghapus salinan cloud atau catatan pihak ketiga.

8. Keamanan, anak-anak, dan perubahan

Kami menggunakan pengamanan yang sesuai dengan layanan, tetapi tidak ada sistem yang sepenuhnya aman. Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun; hubungi kami jika Anda yakin seorang anak telah memberikan data pribadi. Kami dapat memperbarui kebijakan ini dan mengubah tanggal di atas saat praktik berubah.
